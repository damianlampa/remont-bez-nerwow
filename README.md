# Remont bez nerwów

A website for a renovation company. Currently at the initial Astro setup stage.

## Development

Use Node.js 26.13.0 (LTS) and npm 11.20.0. With nvm installed, run `nvm use`.

```sh
npm ci
npm run dev -- --background
```

Manage the server with `npm run astro -- dev status`, `npm run astro -- dev logs`,
and `npm run astro -- dev stop`.

## Production build

```sh
npm run build
npm run preview
```
